    What is happening?
    1. When this page opens, your browser makes a fresh key pair. The server signs your public key so nobody can swap in a fake one.
    2. You and your friend combine your own secret key with the other’s public key and get the same starting secret, without sending it.
    3. Each message gets a one-time key from a one-way chain. Old keys are deleted.
    4. When the conversation changes direction, a fresh key pair is mixed in, which locks out anyone who stole a key earlier.
    5. AES-GCM encrypts the message and detects any change to it or its header.
    6. The message key is also encrypted for the government’s public key and placed in the header.
